---
description: 指定したissueの内容に沿ってbranchを作成し編集する(コミットはしない)
argument-hint: <issue番号 例: #3>
---

対象issue: $ARGUMENTS

1. `$ARGUMENTS` からissue番号を取り出す（`#3`でも`3`でも可）。番号が無ければユーザーに確認する。
2. `git status` で作業ツリーがクリーンか確認する。未コミットの変更があれば、進める前にユーザーに確認する（勝手にstash/discardしない）。
3. `gh issue view <番号>` でissueのタイトル・本文を取得し、要約する。
4. issue内容から作業ブランチ名を決める。暫定ルール: `issue-<番号>-<内容を表す短い英字slug>`（正式なブランチ命名規則は未確定。`CLAUDE.md`のTODO参照）。
5. `git checkout -b <ブランチ名>` でブランチを作成する。
6. issueの内容に沿って実装・編集する。不明点や実装方針に選択肢がある場合は、着手前にユーザーに確認する。
7. 編集したファイルを`git add`でステージする。**コミットはしない**（コミットは`/commit-push`に任せる）。
8. 何を編集したか、次にユーザーが確認・判断すべき点を要約して報告する。
