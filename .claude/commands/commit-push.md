---
description: ステージ済みの変更をコミットしてプッシュする
---

コミットとpushを行う。以下の手順を厳守すること。

## Step 1: ステージ確認

```bash
git diff --cached --name-only
```

ステージされているファイルが0件なら、以下のメッセージを返してそこで終了する：

> ステージされているファイルがありません。`git add` でファイルをステージしてから実行してください。

## Step 2: 削除ファイルの確認

```bash
git diff --cached --name-only --diff-filter=D
```

削除されているファイルがあれば、ファイル名を列挙してユーザーに確認を取る。確認が取れてから次のステップへ進む。

## Step 3: バージョンインクリメント

ステージされているファイルの拡張子を確認し、以下のルールでバージョンを決定する。

**スクリプト変更あり**（拡張子が `.js` `.mjs` `.cjs` `.ts` `.mts` のいずれかが1件以上含まれる場合）:
- `minor` を+1、`patch`を0にリセット

**コンテンツのみ**（`.md` `.tsv` `.txt` など、上記スクリプト以外のみの場合）:
- `patch`のみ+1

`package.json` の `"version"` フィールドを上記ルールで書き換える。書き換え後のバージョン番号を確認すること。

## Step 4: package.json をステージに追加

```bash
git add package.json
```

## Step 5: コミット

コミットメッセージは以下の形式：
- 1行目: 変更内容の要約（日本語可、50文字以内）
- 末尾に必ず以下を付ける（実際のモデル名・バージョンに置き換える）:

```
Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>
```

HEREDOCを使ってコミットする。

## Step 6: Push

```bash
git push
```

push完了後、新しいバージョン番号をユーザーに報告する。
